The model

A Model is built once from a row reader and a row writer. The example below is the exact source the engine on this page was built from.

SourceModel::new
MoonBit
Model::new(
  "accounts",
  [
    column("id", BigIntType,
      primary_key=true, autoincrement=true),
    column("email", TextType,
      nullable=false, unique=true),
    column("balance", RealType),
    column("team_id", BigIntType,
      references=("teams", "id"),
      on_delete="SET NULL"),
    column("status", TextType,
      nullable=false, default="'active'"),
    column("level", IntType,
      checks=["level >= 0"]),
  ],
  from_row, to_row,
)
What it means
A table "accounts" with six columns.
id      → primary key, auto increment
email   → not null, unique
balance → nullable real
team_id → fk → teams(id), SET NULL
status  → not null, default 'active'
level   → integer, checked >= 0
