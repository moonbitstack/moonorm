moonmysql

The MySQL / MariaDB implementation of the Driver contract. A young phase — the core operations are ratified; streaming refines over time.

Enactment

What it is

moonmysql connects to a MySQL or MariaDB server and implements Driver against it. It speaks the ? placeholder token and binds parameters out-of-band where the protocol allows.

i

Install

moon add moonbitstack/moonmysql

ii

Placeholder

? positional. The text protocol has no out-of-band binding until prepared statements land, so values are escaped for the server's actual sql_mode — and the driver says so in its own README.

iii

Coverage

execute query transaction close ping (default) query_stream (default).
