moonpostgres

The PostgreSQL implementation of the Driver contract. Most of the surface is native, and its server-side cursor refines query_stream for bounded memory.

Enactment

What it is

moonpostgres connects to a PostgreSQL server and implements Driver against it. It speaks the $1, $2, … placeholder token and binds parameters out-of-band.

i

Install

moon add moonbitstack/moonpostgres

ii

Placeholder

$1, $2, … positional — PostgreSQL's native numbered placeholders, bound server-side.

iii

Coverage

execute query transaction close query_stream (native cursor) ping (default).
